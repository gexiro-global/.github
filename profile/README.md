### Open Source

Small, focused, permissively licensed tools we maintain in the open. Each is adversarially
tested and fails closed.

**Security & AI**

- **[llm-security-gates](https://github.com/gexiro-global/llm-security-gates)** — Tested Python security gates for LLM guardrails: prompt-injection filtering, model-artifact supply-chain scanning, and garak-based AI red-team scoring.
- **[csaf-check](https://github.com/gexiro-global/csaf-check)** — Python API and CLI to validate CSAF 2.0 security advisories and VEX documents (BSI `@secvisogram/csaf-validator-lib`), with CI-friendly fallback.
- **[ForgeGuard](https://github.com/gexiro-global/forgeguard)** — Read-only security posture self-check for self-hosted Gitea/Forgejo: patch currency, CVE posture, container-registry and sign-in exposure. Own/authorized instances only.
- **[ai-vault-contract](https://github.com/gexiro-global/ai-vault-contract)** — Starter Obsidian vault and agent instructions for AI-maintained knowledge bases (Claude + Codex): dedup, schemas, atomic notes.

**Self-hosting & deployment (bash, run as root — read the safety notes)**

- **[cloudflare-origin-certs](https://github.com/gexiro-global/cloudflare-origin-certs)** — Bulk-issue Cloudflare Origin CA certificates and wire them into OpenLiteSpeed; dry-run by default, transactional install.
- **[cloudflare-ufw-sync](https://github.com/gexiro-global/cloudflare-ufw-sync)** — Keep a UFW allowlist in sync with Cloudflare's IP ranges — additive-only, never locks you out.
- **[wp-hygiene-kit](https://github.com/gexiro-global/wp-hygiene-kit)** — Read-only hygiene checks for multi-site WordPress hosts: discover live installs, ClamAV scan, ownership checks.
- **[deploy-guard-kit](https://github.com/gexiro-global/deploy-guard-kit)** — Read-only pre-flight checks for single-host deploys: dead-port squatting, PM2 cwd drift, and content-marker healthchecks.

**Discovery & SEO**

- **[indexnow-ping](https://github.com/gexiro-global/indexnow-ping)** — Submit sitemap URLs via IndexNow and Google Search Console, with a robots.txt guard that refuses to announce pre-launch sites.
